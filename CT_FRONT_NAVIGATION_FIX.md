# CT frontend navigation fix

Что изменено:

- Главная страница CT-фронта теперь показывает обычные курсы TaskForge из `/api/courses`, а не сразу fallback-конспект.
- Открытие курса ведёт на страницу курса, где показываются учебные направления, сейчас — `ЦТ / ЦЭ 2026`.
- Внутри `ЦТ / ЦЭ 2026` отображаются разделы `A1`, `A2`, ... и т.д.
- Внутри раздела отображаются конспекты и переходы к заданиям.
- Исправлен backend-баг `/api/learning/courses/tree`: раньше он падал на `ParentCourseId = null`.
- Включён безопасный seed learning/quiz данных при пустой БД.
- Убрана явная зависимость `Microsoft.IdentityModel.Tokens`, которая могла давать runtime mismatch при JWT.

Миграции не добавлялись и не генерировались.
