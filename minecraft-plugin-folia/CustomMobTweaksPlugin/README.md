# CustomMobTweaksPlugin

Плагин для Folia с кастомными эффектами мобов.

## Что уже есть
- Blaze small fireball -> молния при попадании
- Bogged arrow -> иссушение
- Wither Skeleton hit -> безопасный "стан"

## Сборка
```powershell
gradle build
```
или через wrapper после его генерации:
```powershell
.\gradlew.bat build
```
