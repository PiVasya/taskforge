# Отчёт проверок обновления cluster dashboard

Дата подготовки: 2026-09-08.

## Выполнено

- 10/10 тестов модели интерфейса через Node.js test runner: отсутствие измерений не превращается в ноль; нулевой lag отображается корректно; состояния контейнеров; standby; устаревшие данные; отсутствие пересечений начальной раскладки для 1–10 серверов; валидация сохранённых координат; запрет localStorage; матрица назначений и исключений lite.
- Все новые JSX/JS-модули и главная страница транспилированы TypeScript transpileModule без синтаксических диагностик. Это проверка синтаксиса, не замена сборки react-scripts.
- `check-architecture.js`: PASS, включая 45 SPA/Caddy-маршрутов.
- `check-csharp-source-invariants.py`: PASS. Это статическая проверка, не компиляция C#.
- `check-workflow-integrity.py`: PASS.
- `check-cluster-ha.sh`: PASS. Проверяет исходный встроенный deploy из ZIP; не означает испытание живого r57-кластера. Изменены только устаревшие проверки монолитной UI-страницы в `check-cluster-control-v40.sh`, чтобы проверять новые компоненты и запускать тесты модели. Остальные HA-проверки сохранены.
- 25 проверок React-компонентов в Chromium: компактная сводка, большая карта, отсутствие перекрытия карточек; выбранная нода, поиск контейнеров и образов, цвет prepared-standby, клавиатурные вкладки, адреса, вызов копирования, обработка перемещения, сохранение позиции и выбора после запроса API, ошибка обновления, устаревший снимок, отсутствие горизонтального переполнения всей страницы при ширине 1560 и 390 px, отсутствие JS runtime errors.
- Проверены изображения светлой и тёмной тем на десктопе и узком экране.

## Важные границы браузерной проверки

Визуальный стенд рендерит настоящие новые компоненты и их CSS с React 18.2. API, ReactFlow, иконки, clipboard и localStorage в этом стенде заменены тестовыми реализациями. Проверены обработчики и логика состояния страницы, но НЕ полная интеграция настоящей библиотеки ReactFlow в собранном приложении. Скриншоты используют вымышленные адреса диапазона 198.51.100.0/24 и демонстрационные значения; это не снимок пользовательского production.

В исходниках приложения нет этой подмены, фикстур, заглушек или демонстрационных IP. Production импортирует существующий `reactflow` и запрашивает настоящий `/api/admin/cluster`.

## Не выполнено в этой среде

- Полный `npm ci` / `npm run build`: установка зависимостей не завершилась из-за недоступной сети. Нельзя считать полный production bundle проверенным.
- Компиляция C# и запуск `tools/cluster-telemetry-check`: .NET SDK в среде отсутствует. Регрессионный проект добавлен в архив, но его проверки здесь не запускались. Он проверяет именно нормализацию r57, адреса, исключение секретов, snapshots, standby без сертификата, конфликты/устаревшую Primary, стабильные ID событий и старый объектный формат сервисов.
- Реальное развёртывание, доступ к пользовательским VPS, live API, измерения ресурсов серверов и аварийное переключение кластера. Этих действий не выполнялось.

## Что не менялось

Нет изменений в `deploy/`, `infrastructure/`, `apps/gateway/`, схеме БД или её миграциях. Серверный архив r57 не создавался заново и не исправлялся. Политика debug logging, роли и протокол failover не изменены. Изменение касается административного представления данных и интерфейса; управляющих кнопок/новых операций с сервером не добавлено.

Перед выкладкой требуется успешная штатная сборка `front` и `observability-api`. После выкладки проверить карту с настоящим ReactFlow, сохранение расстановки и реальные данные API по инструкции.
