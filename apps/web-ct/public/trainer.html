Гласная в корне слова

Алгоритм решения A1

Шаг 1. Проверить, нет ли корня с чередующимися гласными

  • кас — -а- — кос: касаться, коснуться
  • гар — гор: загар, загореть
  • клан — клон: кланяться, поклон
  • твар — твор: тварь, творить
  • зар — зор: заря, зорька
  • скак — скоч: скакать, вскочить
  • раст / ращ / рос: растение, выращенный, росли
  • лаг — лож: полагать, положить
  • мак — мок / моч: макать, промокнуть, мочить
  • равн — ровн: равный, ровный
  • плав — плов / плыв: плавать, пловец, плывун

Шаг 2. Пытаемся подобрать проверочное слово

Нужно подобрать однокоренное слово так, чтобы слышно было, какая гласная в корне.

побледневший — бледный

удивляться — диво

⚠ Нельзя подбирать слова с суффиксами -ива-, -ыва-, когда ищем однокоренное слово для проверки.

опоздать — опаздывать: так не проверяем

опоздать — поздний: так проверяем

Шаг 3. Если не можем подобрать слово, то оно словарное

Такие слова нужно запоминать. Для них в обучалке есть отдельная страница.

🌳 Лайфхак
В этом задании обычно:
1 слово словарное,
2 слова на чередование,
2 слова на проверяемую гласную.
↝ Упражнение

1. Пол__жить вещи / Пол__гаться на друга

2. Г__реть на солнце / Уг__рать в бане

3. Пл__вец / Пл__вучий остров / Зап__сной вариант

1. Положить / полагаться. Корень лаг/лож: перед ж пишем о, перед г — а.

2. Гореть / угорать. Корень гар/гор: без ударения обычно пишется о, под ударением — а.

3. Пловец / плавучий / запасной. Пловец — исключение, плавучий — корень плав, запасной проверяется словом запас.

Корни с чередующимися гласными

Сначала ищем именно эти корни. Если слово попало сюда, обычное проверочное слово подбирать нельзя: работает правило чередования.

Корни и базовые пары
кас — -а- — кос гар — гор клан — клон твар — твор зар — зор скак — скоч раст — ращ — рос лаг — лож мак — мок / моч равн — ровн плав — плов / плыв
Исключения

гар/гор: пригарь, выгарки, утварь, изгарь

скак/скоч: скачу, скачок, скачкообразный

раст/ращ/рос: росток, Ростов, Ростислав, ростовщик, отрасль, вырост, подростковый, подросток, полог

равн/ровн: поровну, уровень, ровесник, равнина, поравняться, сравнить, равнение

плав/плов/плыв: пловец, пловчиха, плывун

Короткие подсказки

лаг/лож: перед г обычно пишется а, перед ж — о: полагать — положить.

кас/кос: если после корня есть суффикс -а-, пишется а: касаться. Без суффикса — о: коснуться.

раст/ращ/рос: перед ст и щ пишется а, перед с — о, но есть исключения.

мак/мок: мак — погружать в жидкость, мок/моч — впитывать влагу.

равн/ровн: равн — одинаковый, ровн — гладкий, прямой.

Словарные слова

Эти слова нельзя нормально проверить ударением. Их лучше учить отдельными порциями. Сейчас они спрятаны: можно открыть, когда понадобится.

Слова из ЦТ / ЦЭ прошлых лет

Это отдельный блок для повторения. Слова разделены по годам и по буквам А / О, как на картинках.

Тренировка
