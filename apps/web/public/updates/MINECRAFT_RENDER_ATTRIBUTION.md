# Minecraft mob render attribution

The mob cards in `minecraft-integration-mobs.json` use transparent PNG renders from:

- `IsaiahPapa/minecraft-render-pipeline` through jsDelivr.
- The pipeline is MIT-licensed and generates renders from Mojang's `bedrock-samples` entity assets.
- Minecraft assets remain property of Mojang Studios / Microsoft.
- The Illusioner image is loaded from Minecraft Wiki/Fandom because the render pipeline manifest marks this Java-only entity as a manual asset without generated PNG output.
