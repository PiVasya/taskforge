# Minecraft mob render attribution

Mob cards use static renders by default. Some mob cards also display animated renders while visible, and fall back to static headshots.

- Static renders: `IsaiahPapa/minecraft-render-pipeline`, generated from Mojang sample assets, plus Minecraft Wiki renders where needed.
- Blaze and Breeze animations: Minecraft Wiki/Fandom.
- Parched and Vindicator animations: `IsaiahPapa/minecraft-render-pipeline` (Bedrock sample renders).

No canvas, WebGL, frame compositor, continuous JavaScript animation loop, or server-side rendering is used.
