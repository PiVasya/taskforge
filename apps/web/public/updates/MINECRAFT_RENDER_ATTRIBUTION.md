# Minecraft mob render attribution

The mob cards in `minecraft-integration-mobs.json` use animated mob renders from Minecraft Wiki/Fandom and animated WebP renders from `IsaiahPapa/minecraft-render-pipeline` through jsDelivr.

- Blaze uses the animated GIF published by Minecraft Wiki/Fandom, with a local static fallback.
- Breeze uses the animated Java Edition GIF from Minecraft Wiki, with an animated WebP fallback.
- Bogged and the other supported mobs use animated `spin.webp` renders generated from Mojang Bedrock sample assets; static or wiki fallbacks are configured where available.
- Illusioner uses the Java Edition render from Minecraft Wiki/Fandom.
- Minecraft assets remain property of Mojang Studios / Microsoft.
