# CustomMobTweaks 2.0.0

Единый Folia-плагин усиления мобов для Minecraft/Folia **26.1.2** и Java **25**.
В проект перенесены и переработаны механики `CreakingPerks 1.0`, при этом сохранены старые возможности `CustomMobTweaks`.

## Основные усиления

- **Вихрь (Breeze)**
  - дополнительные быстрые выстрелы зарядами ветра;
  - поиск ближайшей видимой цели;
  - дождь из зарядов ветра после попадания по игроку;
  - визуальный взрыв и настраиваемое отбрасывание при попадании;
  - опциональная радиационная зона;
  - отдельная старая атака огненным шаром сохранена и не заменяет специальные заряды нового модуля;
  - настраиваемый дополнительный лут, включая элитры.

- **Скрипун (Creaking)**
  - увеличенная скорость;
  - фиксируемый урон;
  - слепота при ударе;
  - тьма для игроков рядом.

- **Болотник (Bogged)**
  - кровотечение/яд после попадания;
  - зелёные лужи на земле;
  - лужа лечит и временно усиливает моба, который в неё вошёл;
  - настраиваются размер, длительность и множитель урона усиленного моба.

- **Зимогор (Stray)**
  - длительная заморозка;
  - периодическое уменьшение максимального здоровья либо прямой урон;
  - восстановление максимального здоровья после окончания эффекта.

- **Броненосец**
  - после получения урона создаёт защитную сферу;
  - радиус сферы растёт с потерей здоровья;
  - вошедшие игроки отбрасываются.

- **Иллюзионист**
  - может заменять естественно появившегося враждебного моба;
  - может отдельно появляться около игроков;
  - без фиолетового имени и без принудительного отображения ника;
  - шанс, радиус, освещение, здоровье и лут настраиваются.

- **Зомби с трезубцем**
  - отдельный шанс появления среди обычных зомби;
  - увеличенные здоровье, урон и скорость;
  - действительно бросает трезубцы на расстоянии;
  - дальность, скорость полёта, урон и задержка выстрела настраиваются;
  - отдельный шанс выпадения трезубца и другого лута.

## Остальные перенесённые механики CreakingPerks

- снежки замораживают и накладывают усталость;
- лава повреждает обычную броню;
- полный незеритовый комплект получает отдельную механику урона, ремонта и плавления предметов;
- «Сухое оружие» из меди и сухой листвы;
- режим бомбардировщика на счастливом гасте с TNT и зарядами ветра;
- радиационные зоны с частицами, огнём, отбрасыванием и выпадением случайных предметов.

## Сохранённые старые усиления CustomMobTweaks

- молния от огненного шара ифрита;
- иссушение от стрелы болотника;
- оглушение от визер-скелета;
- урон снежками снеговика;
- усиленные заряды и огненные шары вихря;
- свечение от трезубца утопленника;
- пробитие брони разбойником;
- замедление от зимогора;
- снайперские и самонаводящиеся стрелы скелетов.

## Дополнительный лут

Раздел `extra-loot` позволяет отдельно включать лут каждого усиленного моба. Для каждого предмета доступны:

```yaml
material: ELYTRA
chance: 0.02
looting-bonus-per-level: 0.0025
min-amount: 1
max-amount: 1
```

`chance` можно задавать как долю (`0.02` = 2%) или процент (`2` = 2%).
Любой список можно расширять собственными подразделами с материалами Minecraft.

В стартовом конфиге уже добавлены варианты для вихря, зомби с трезубцем, скрипуна, болотника, зимогора, броненосца, иллюзиониста, утопленника, ифрита, визер-скелета, разбойника, снеговика и скелета-снайпера.

## Команды

```text
/custommobtweaks modules
/custommobtweaks reload
/custommobtweaks bomber on
/custommobtweaks bomber off
/custommobtweaks bomber status
```

Сокращения: `/cmt`, `/mobtweaks`.

Права:

```text
custommobtweaks.admin
custommobtweaks.bomber
```

## Сборка

```bash
cd taskforge-develop/plugins/minecraft/minecraft-plugin-folia/CustomMobTweaksPlugin
gradle clean build
```

Требуются Java 25 и Gradle с поддержкой Java 25.
Результат:

```text
build/libs/CustomMobTweaks-2.0.0.jar
```

После первого запуска рабочий конфиг появится здесь:

```text
plugins/CustomMobTweaks/config.yml
```
