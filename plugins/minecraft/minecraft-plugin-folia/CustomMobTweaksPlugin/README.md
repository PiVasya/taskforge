# CustomMobTweaks 2.3.0

Единый Folia-плагин усиления мобов для Minecraft/Folia **26.1.2** и Java **25**.
В проект перенесены и переработаны механики `CreakingPerks 1.0`, при этом сохранены старые возможности `CustomMobTweaks`.

## Основные усиления

- **Вихрь (Breeze)**
  - дополнительные быстрые выстрелы зарядами ветра;
  - поиск ближайшей видимой цели;
  - дождь из зарядов ветра после попадания по игроку;
  - визуальный взрыв и настраиваемое отбрасывание при попадании;
  - отдельная старая атака огненным шаром сохранена и не заменяет специальные заряды нового модуля;
  - дополнительный лут; элитра выпадает по настраиваемому шансу.

- **Скрипун (Creaking)**
  - увеличенная скорость;
  - фиксируемый урон;
  - слепота при ударе;
  - тьма для игроков рядом.

- **Болотник (Bogged)**
  - кровотечение/яд после попадания;
  - зелёные лужи на земле;
  - лужа лечит и временно усиливает моба, который в неё вошёл;
  - настраиваются размер, длительность и множитель урона усиленного моба.

- **Зимогор (Stray)**
  - длительная заморозка;
  - периодическое уменьшение максимального здоровья либо прямой урон;
  - восстановление максимального здоровья после окончания эффекта.

- **Броненосец**
  - после получения урона создаёт защитную сферу;
  - радиус сферы растёт с потерей здоровья;
  - вошедшие игроки отбрасываются.

- **Иллюзионист**
  - может заменять естественно появившегося враждебного моба;
  - может отдельно появляться около игроков;
  - без фиолетового имени и без принудительного отображения ника;
  - каждый выстрел создаёт рядом одну копию с 1 HP;
  - копии тоже стреляют и создают следующее поколение копий;
  - одновременно у одного оригинала может существовать не больше 30 копий;
  - поколения живут 15, 13, 11, 9, 7, 5 и 3 секунды;
  - после смерти оригинала оставшиеся копии рассыпаются через 2 секунды;
  - копии не дают опыт и лут, а их урон по умолчанию составляет 35% обычного;
  - шанс, радиус, освещение, здоровье, клоны и лут настраиваются.

- **Зомби с трезубцем**
  - отдельный шанс появления среди обычных зомби;
  - увеличенные здоровье, урон и скорость;
  - действительно бросает трезубцы на расстоянии;
  - дальность, скорость полёта, урон и задержка выстрела настраиваются;
  - отдельный шанс выпадения трезубца и другого лута.

- **Эндер-дракон**
  - основной ванильный дракон сохраняет стандартный бой и AI;
  - его настоящий драконий шар заменяется длинным движущимся 3D-потоком огня по фактическому направлению снаряда;
  - поток расширяется к середине и сужается к концу, использует оранжевое и фиолетовое пламя, `DRAGON_BREATH` и краевой дым;
  - блоки огня не ставятся;
  - каждая отдельная посадка основного дракона на центральный портал создаёт одну настоящую уменьшенную сущность `EnderDragon`, пока не достигнут лимит;
  - копия помечается PDC-ключами `taskforge:dragonling` и `taskforge:dragonling_owner`, не дышит, не стреляет шарами, не лечится от кристаллов, не показывает отдельный боссбар и не выдаёт боссовый лут/опыт;
  - копия регулярно выбирает живого отслеживающего игрока и переходит в частое `CHARGE_PLAYER`;
  - после смерти основного дракона принадлежащие ему копии удаляются.

## Переработка эндер-дракона

Модуль `ender-dragon-rework` встроен в общий component lifecycle плагина и не использует EI, SCore, `ItemDisplay`, фантома-носителя, ресурспак, базу или отдельную боевую сессию. API-созданные уменьшенные драконы не относятся к ванильной `DragonBattle`, поэтому не завершают бой, не создают яйцо и не открывают выходной портал.

Стартовые настройки:

```yaml
ender-dragon-rework:
  enabled: true
  fire-stream:
    enabled: true
    length: 48.0
    speed-blocks-per-tick: 3.0
    minimum-radius: 0.45
    maximum-radius: 3.2
    damage: 8.0
  dragonling:
    scale: 0.25
    health: 40.0
    maximum-active: 2
    charge-cooldown-min-ticks: 40
    charge-cooldown-max-ticks: 80
    target-range: 72.0
    collision-damage: 6.0
```

Поток запускается только событием реального выстрела основного дракона. Его последовательные срезы выполняются через region scheduler конкретных точек, а урон и поджигание — через entity scheduler каждого игрока. У каждой уменьшенной копии отдельный entity scheduler контроллера; глобального опроса драконов или игроков нет. При `/cmt reload` потоки, проверки посадки и контроллеры останавливаются, слушатель снимается, а помеченные копии удаляются без затрагивания основного дракона.

## Копии иллюзиониста

Модуль `illusioner-clones` не использует глобальный таймер и не перебирает всех мобов. Выстрел только запускает создание копии: безопасное место проверяется и сущность создаётся через Folia region scheduler нужной локации, а исчезновение назначается на собственном entity scheduler копии.

Стартовые ограничения:

```yaml
illusioner-clones:
  max-active-per-original: 30
  max-generation: 7
  base-lifetime-ticks: 300
  lifetime-reduction-per-generation-ticks: 40
  minimum-lifetime-ticks: 60
  max-health: 1.0
  damage-multiplier: 0.35
```

Формула времени жизни: первое поколение живёт 15 секунд, каждое следующее на 2 секунды меньше, но никогда не меньше 3 секунд. Седьмое поколение продолжает стрелять, но уже не создаёт восьмое. Лимит 30 считается отдельно для каждого настоящего иллюзиониста и защищён атомарным счётчиком, поэтому одновременные выстрелы из разных Folia-регионов не могут превысить потолок.

Копии помечаются через `PersistentDataContainer`: сохраняются UUID оригинала и номер поколения. Это предотвращает выдачу дополнительного лута и не даёт копиям блокировать обычный редкий спавн настоящего иллюзиониста. Сами копии непостоянные: они не сохраняются в мире при остановке сервера и не могут остаться «вечными» после перезапуска.

## Остальные перенесённые механики CreakingPerks

- снежки замораживают и накладывают усталость;
- лава повреждает обычную броню;
- полный незеритовый комплект получает отдельную механику урона, ремонта и плавления предметов;
- «Сухое оружие» из меди и сухой листвы;
- режим бомбардировщика на счастливом гасте с TNT и зарядами ветра;
- радиоактивные зоны полностью удалены: ни вихрь, ни режим счастливого гаста больше их не создают.

## Сохранённые старые усиления CustomMobTweaks

- молния от огненного шара ифрита;
- иссушение от стрелы болотника;
- оглушение от визер-скелета;
- урон снежками снеговика;
- усиленные заряды и огненные шары вихря;
- свечение от трезубца утопленника;
- пробитие брони разбойником;
- замедление от зимогора;
- снайперские и самонаводящиеся стрелы только у обычного ванильного скелета; зимогор, болотник и визер-скелет не затрагиваются.

## Дополнительный лут

Раздел `extra-loot` позволяет отдельно включать лут каждого усиленного моба. Для каждого предмета доступны:

```yaml
material: ELYTRA
chance: 0.02
looting-bonus-per-level: 0.0025
min-amount: 1
max-amount: 1
```

`chance` можно задавать как долю (`0.02` = 2%) или процент (`2` = 2%). Для `POTION`, `SPLASH_POTION`, `LINGERING_POTION` и `TIPPED_ARROW` можно дополнительно указать `potion-type`, например `POISON`, `LONG_SLOWNESS` или `STRONG_SLOWNESS`.
Элитра вихря проходит через тот же механизм вероятности, что и остальные предметы. В стартовом конфиге установлен шанс `0.05` (5%), без принудительной гарантии.
Любой список можно расширять собственными подразделами с материалами Minecraft.

В стартовом конфиге уже добавлены варианты для вихря, зомби с трезубцем, скрипуна, болотника, зимогора, броненосца, иллюзиониста, утопленника, ифрита, визер-скелета, разбойника, снеговика и скелета-снайпера.

## Команды

```text
/custommobtweaks modules
/custommobtweaks reload
/custommobtweaks bomber on
/custommobtweaks bomber off
/custommobtweaks bomber status
```

Сокращения: `/cmt`, `/mobtweaks`.

`/cmt reload` — полноценная горячая перезагрузка: старые слушатели снимаются, отслеживаемые Folia-задачи отменяются, `config.yml` перечитывается, после чего все модули создаются заново. Перезапуск Minecraft-сервера не требуется.

Права:

```text
custommobtweaks.admin
custommobtweaks.bomber
```

## Сборка

```bash
cd taskforge-develop/plugins/minecraft/minecraft-plugin-folia/CustomMobTweaksPlugin
gradle clean build
```

Требуются Java 25 и Gradle с поддержкой Java 25.
Результат:

```text
build/libs/CustomMobTweaks-2.3.0.jar
```

После первого запуска рабочий конфиг появится здесь:

```text
plugins/CustomMobTweaks/config.yml
```
