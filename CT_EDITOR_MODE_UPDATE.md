# CT editor mode update

Что изменено:

- `clientapp-ct` больше не использует отдельный непонятный JSON-only редактор конспектов как основной сценарий.
- Добавлен режим редактора, похожий по логике на старый фронт: переключатель в верхней панели открывает те же учебные курсы, но в окне редактирования.
- Главная и страницы курсов в режиме редактора ведут на `/editor/courses/:courseSlug`.
- Редактор работает с новой CT-моделью: `LearningCourse -> LearningConspect -> QuizTask`, а не со старыми программными курсами TaskForge.
- A1/A2/B10 и т.п. не захардкожены на фронте. Это обычные значения поля `sectionCode`, которые можно вводить при создании/редактировании раздела.
- Добавлено нормальное создание дочернего курса/раздела/темы внутри выбранного узла.
- Добавлено редактирование курса/раздела в форме: название, slug, short title, описания, subjectCode, examCode, sectionCode, sortOrder, публикация.
- Добавлено редактирование конспекта через формы и блочный builder: вкладки, текст, правила, предупреждения, примеры, словарь, кнопка к заданиям.
- Расширенный JSON оставлен как запасной режим для сложной точной правки, но он больше не основной способ редактирования.

Миграции не создавались.
