# CT editor simplified update

## Что изменено

Редактор второго фронта больше не ведёт в старое дерево курсов и старые ветки.

Теперь основной редактор работает по номерам ЦТ:

- `/editor` перенаправляет на `/editor/a1`;
- `/editor/a1`, `/editor/a2`, ..., `/editor/b10` открывают редактор конкретного номера;
- старый путь `/editor/courses/:courseSlug` перенаправляет на `/editor/a1`;
- переключатель «Редактор» из страницы ученика `/a1` ведёт сразу в `/editor/a1`.

## Как работает редактор

В левой части редактора находится сетка номеров:

- A1-A30;
- B1-B10.

В правой части выбранного номера:

1. HTML-конспект для выбранного номера.
2. Задания для выбранного номера.

Например, `/editor/b5` редактирует:

- HTML-конспект с `sectionCode = "B5"`;
- задания с `sectionCode = "B5"`.

## База данных

Новых миграций нет.

Редактор использует уже существующие сущности:

- `LearningCourse` как служебный раздел с `sectionCode`;
- `LearningConspect` для HTML-конспекта;
- `QuizTask` для заданий.

Если служебный раздел в БД ещё не создан, редактор может создать его автоматически при сохранении конспекта или через кнопку «Создать A1 в БД».
