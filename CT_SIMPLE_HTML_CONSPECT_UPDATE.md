# CT simple HTML conspect editor update

## Главное

Конспекты упрощены: редактор больше не заставляет собирать сложный JSON из вкладок и блоков. Теперь конспект можно хранить как обычный HTML.

Формат хранения остался в существующем поле `ContentJson`, поэтому миграции не нужны:

```json
{
  "schemaVersion": 2,
  "mode": "html",
  "html": "<section>...</section>",
  "updatedAtUtc": "..."
}
```

Старые JSON-блочные конспекты продолжают отображаться старым renderer-ом.

## Исправлено

- Редактор показывает серые подсказки почти под каждым полем.
- Кнопка `Новый конспект` теперь явно создаёт черновую форму и пишет сообщение, что дальше надо нажать `Сохранить конспект`.
- Ошибки API нормализуются на фронте и показываются понятным текстом.
- Backend learning-content-service возвращает JSON-ошибки с `message`, `detail`, `hint`.
- Добавлена защита от дублей slug для курсов и конспектов.
- В nginx repo-конфиги добавлены `/api/admin/learning/` и `/api/admin/quiz/`.

## Важно для сервера

Если серверный nginx-конфиг лежит отдельно от репозитория, нужно обновить nginx-конфиг на сервере. Иначе POST `/api/admin/learning/...` будет уходить в старый общий API и давать 404.
